# ゴールデン

determinism.md §10。入力と画素のダイジェストを版つきで凍結した行。全ターゲットで同じファイルを照らす
（`cargo test -p sumie --test golden`）。

| ファイル | 中身 | 書き換え |
|---|---|---|
| `render-v<N>.jsonl` | 版 `sumie-render/<N>` の描いた結果（D1） | 凍結した版は**追記だけ**（`scripts/check-goldens-append-only.sh`）。版 0 は今の版が 0 の間（M7 まで）作り直してよい（ADR-20。作り直すときはコミットを分け、差の一覧を付ける）。今の版が 1 以上になったら、版 0 も古い版として凍結する（ADR-56 (3)）。版 0 の作り直しは、版を上げる前に main に入れる（同じ枝で作り直してから版を上げると、main との比べで「古い版を変えた」になる）。今の版より古い版のファイルは追記もしない（ADR-51 (5)） |
| `estimate.jsonl` | 見積もりと警告の並び（D2。ADR-33） | rev ごとに作り直してよい |

`render-v<N>.jsonl` の 1 行（鍵はこの順。値は文字列か整数。行のバイトは正規の形＝`sumie_testkit::jsonl::Line` で読み直して
書くと同じ。ファイルは改行で終わり、CR を持たない）：

| 鍵 | 中身 |
|---|---|
| `name` | 例の名前（ファイルの中で重ならない。中身を変えたいときは新しい名前の例を足す） |
| `input` | 入力の SVG のバイト列の BLAKE3（小文字の 16 進 64 桁）。行は入力をこのダイジェストで指す |
| `path` | 入力の場所の手がかり（workspace の根からの相対の道。`tests/svg/` か `corpus/` の下。`..` なし）。照らすときはダイジェストで引くので、入力を動かしても古い行は壊れない |
| `fonts` | フォントの鍵（`tests/fonts/` のファイルの BLAKE3）の並びを `,` でつないだもの（なければ空） |
| `decoder` | 画像のデコーダの識別子（なければ空） |
| `style` | 読みの設定（architecture.md §3 の `StyleDefaults`）。既定（`StyleDefaults::USVG`）なら `default`、ほかは正規の並びの BLAKE3（並べ方は M1 で `StyleDefaults` を作るときに決めてここに書く） |
| `scale` | 倍率（正規の 10 進の字句：`1`・`0.5`。符号・指数・末尾の 0 なし） |
| `region` | 範囲（`x,y,w,h`。正規の 10 進。w・h は 1 以上で、`width`・`height` と同じ。全体なら空） |
| `width`・`height` | 画素の大きさ |
| `pixels` | 画素の BLAKE3。入力のバイト列は、幅・高さをそれぞれ u32 のリトルエンディアン（計 8 バイト）、続けて行を詰めた RGBA8 乗算済み |
| `report` | 版に入る報告（使ったフォントの鍵と書体の番号・見つからなかった文字・デコーダの識別子）の BLAKE3。並べ方は M2 の最初の行の前に決めてここに書く |

今の版の行が指す入力（`tests/svg/`・`corpus/`）とフォント（`tests/fonts/`）は消さない・中身を変えない（消すときは版を上げて、
新しい版のファイルから外す）。`goldens/` には `.jsonl` と README.md だけを置く。

照らすのは今の版のファイルだけ。古い版のファイルは形だけを確かめ（入力を引かない）、凍結したら変えない
（`check-goldens-append-only.sh`）。古い版の例の名前は、すべて次の版のファイルにもある（版を上げたら全部の例を描き
直す。ADR-41 (7)）。

`estimate.jsonl` の形は、見積もりの口ができる M1 で決めてここに書く。
